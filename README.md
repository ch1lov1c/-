# Кондитерская и пекарня «Прованс & Мёд» 🥐🍰

Красивый адаптивный сайт крафтовой кондитерской и пекарни с каталогом фирменных десертов, интерактивной корзиной заказа, детальным просмотром и формой обратной связи.

## Ссылка на сайт (GitHub Pages)
👉 **https://ch1lov1c.github.io/-/**

## Особенности сайта
- 🍰 **Фирменное меню**:
  - Торт «Красный бархат»
  - Домашний ягодный пирог с малиной и смородиной
  - Торт «Медовик классический»
  - Баварский сахарный крендель
  - Французские эклеры с тёмным шоколадом и ягодами
- 🧺 **Интерактивная корзина**:
  - Добавление и изменение количества товаров
  - Автоматический подсчёт суммы и стоимости доставки
  - Сохранение корзины в `localStorage`
  - Оформление заказа во всплывающем окне с генерацией номера заказа
- 🔍 **Быстрый просмотр десерта**:
  - Модальное окно с подробным описанием, составом, БЖУ, калорийностью и аллергенами
- 📱 **100% Адаптивный дизайн**:
  - Оптимизирован под мобильные телефоны, планшеты и десктопы
  - Мобильное всплывающее меню
  - Тёплая крафтовая палитра (Cormorant Garamond + Plus Jakarta Sans)
- 🚀 **Автоматический деплой на GitHub Pages**:
  - Настроен GitHub Actions workflow `.github/workflows/deploy.yml`

## Публикация на GitHub Pages
1. В настройках репозитория: `Settings` → `Pages`
2. В секции **Build and deployment**:
   - **Source**: `Deploy from a branch` → ветка `main` / `/ (root)`
   - Либо **Source**: `GitHub Actions` (workflow уже настроен в `.github/workflows/deploy.yml`)
